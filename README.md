# 奇珍室 · A Cabinet of Curiosities

> 有人把一只空文件夹放在桌上，说：给你三个小时，随便创造点什么，只要它值得留下。
>
> 于是有了这间屋子。十二件展品，跨交互、生成艺术、声音、文字与装置。全部离线，双击即开，不需要网络。

---

## 怎么打开

双击 **`00_从这里开始.html`**，用 Chrome 或 Edge 打开（本机两个都有）。
从门户进入任一展品；每件作品的左上角都有「← 奇珍室」可以返回。

- 建议全屏（F11）。深色展厅在亮环境下会损失细节。
- 除《三小时》外，所有声音默认关闭，由你点击后才会响。
- 所有交互都支持鼠标与触屏；键盘用户可用 Tab / Enter 浏览目录。

## 目录结构

```
创造/
├─ index.html              ← 快捷入口（自动跳转到门户）
├─ 00_从这里开始.html      ← 门户 / 策展前言
├─ 00_关于这间屋子.html    ← 本说明的 HTML 版（推荐在浏览器里看）
├─ 奇珍室_图录.pdf          ← A4 图录，可打印装订
├─ 奇珍室_明信片.pdf        ← A4 四张明信片正反面，裁切即用
├─ 01_涟漪/ … 12_回声/     ← 十二件展品，各自 index.html + README.md
├─ _assets/                ← 制作说明、图录生成器、验收脚本、截图

```

`_assets/制作说明.md` 记录了每件作品的技术实现，以及如何重跑生成脚本；重跑图录只需 `node _assets/build_catalogue.mjs`。

每个展品目录里的 `README.md` 写明了该件的概念、操作方式与技术要点。

## 它是怎么被做出来的

- **前端**：全部是手写的原生 HTML / CSS / JavaScript，没有框架、没有构建步骤、没有外部依赖；所有页面在 `file://` 协议下直接运行。
- **图形**：Canvas 2D 逐像素/逐路径绘制；《晶园》用扩散限制聚集（DLA），《涟漪》用二维波动方程数值解，《造物机》用种子化伪随机数生成 SVG 生物。
- **声音**：WebAudio 实时合成（涟漪的泛音）；《三小时》由 numpy 手写加法合成与混响，离线渲染成 WAV，并另存 MIDI。
- **图像**：Pillow + numpy 程序化绘制，固定随机种子，`generate.py` 可重跑。
- **文字**：全部原创。
- **图录**：Chrome 无头模式将 HTML 排印稿打印为 PDF。

## 三条承诺

1. **不含任何真实人物的信息**——没有人名、学校、单位、账号、网址，也没有引用任何私人文件。作品里出现的人名全部虚构。
2. **不联网**——没有 CDN、没有外链字体、没有统计脚本，断网也能完整运行。
3. **可被继续修改**——每件作品都是单文件，代码没有压缩，生成脚本带注释，欢迎拆开、改参数、重跑。

## 验收结果

- **14 个页面**（门户、说明 + 12 件展品）在 1440×900 与 390×844 两个视口下：**0 个 JS 异常、0 条控制台错误、0 处横向溢出**。
- 所有本地 `src` / `href` 引用均存在，无 404；返回链接逐一可达。
- 全站 **0 个外部请求**（无 CDN、无外链字体、无统计脚本），断网可用。
- 隐私扫描：全站无真实人名、学校、单位、网址、账号。
- 《三小时》WAV：180.000 s / 44.1 kHz / 16 bit / 立体声，峰值 −1.00 dBFS，无 NaN 与削波；播放、循环、跳段均实测通过。
- 唯一需要人耳复核的：音乐 01:55–02:05 的音色平衡（合成器作者无法试听）。

## 已知限制

- 在 `file://` 下，浏览器会限制部分 API（如跨文件 `fetch`、ES Module）。本作品集特意避开了它们，因此单文件体积略大。
- 《时间胶囊》的封条是诗意的约定，不是密码学保险箱；懂技术的人可以拆开它。不过它确实在等 2027 年 1 月 1 日。
- 部分生成算法依赖随机种子；同一台机器、同一浏览器下结果稳定，换环境仍可复现（种子写在各脚本里）。
