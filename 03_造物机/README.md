# 《造物机》 N°03

给它一个种子（任何文字或数字），它交出一只不存在的生物的博物学图版：左侧是标本图，右侧是分类标签卡。同一颗种子永远得到同一只生物。

**操作**：输入种子 → 回车（或点「生成」）；`空格` 再摇一次；「分享」把种子写进地址栏（`#seed=…`），把链接发给别人，打开就是同一只；「保存图版」导出 1800×1800 的 SVG 或 PNG；「图鉴」用 localStorage 存下喜欢的，可回看、可删。彩蛋：输入「种子」。

**技术**：字符串 FNV-1a 哈希 → mulberry32 伪随机。体型由 5 种原型（鱼/盘/甲/蠕/翼）的轮廓结（12 个控制点）经 Catmull-Rom 插值加波状涟漪生成；附肢是沿法线生长的渐细折线（带关节、末端刚毛）；表面纹样、鳃弧、甲片、体节全部用 `clipPath` 裁进躯干；整幅 SVG 字符串渲染，因此同一份 markup 既上屏、也做缩略图、也做导出。图版右下方的圆窗把眼睛放大 3 倍。全离线、单文件、无 `type="module"`、无网络请求。
