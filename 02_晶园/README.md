# 《晶园》 N°02

一杯过饱和的矿液。你点一下，就种下一颗晶核；晶体按扩散限制聚集（DLA）一点点长成分形的枝晶，几天（几分钟）后整个容器开满矿物花。它不解释自己，只是长。

**操作**：容器内任意处点击 / 轻触 → 种下晶核（贴着已有晶体则是"浇灌"，那株会继续长）；`新晶种` 随机种一株；`六方对称` 让已有晶体当场补成六重对称，此后新生长保持晶系；`速度 ×1/×2/×4` 依次加速、再点暂停；`清空`；`保存 PNG` 导出 2400×2400 并带生长记录。键盘：空格暂停、N 新晶种、S 对称、C 清空、P 导出、M 声音。声音默认静音，开启后按色相发一个五声音。

**技术**：640×640 逻辑网格（`Uint8Array` 占位 + 色相索引），粒子从投放环随机游走、碰面按 0.75 概率粘附，走散即重投；每帧只结算 8 次沉积，所以生长是"一格一格"浮现而不是瞬间拉满。粘附点的极角决定色相（湖青→藕荷），半径叠正弦色带做环状生长纹，暴露面越多越亮（1px 亮线），再叠 80/160/320 三层同色辉光。镜头自动取景：统计晶体包围盒，缓动缩放到画幅 56%，所以生长时镜头会慢慢拉远。导出用同一机位重绘，角落留一行极小的生长记录（晶核 / 沉积 / 耗时）。

**彩蛋**：保存的 PNG 右下角比画面上多一行「生长记录」——晶核数、沉积格数、生长耗时与时间戳。
