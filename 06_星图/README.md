# 《数字星图》 N°06

把数学结构当成夜空来观测：三张 2400×3600 的生成图版，同一套"科学图版"版式。

**操作**：打开 `index.html`，点任意一张放大，Esc 或点击关闭；手机上单列排列。

**技术**：Python 3.11 + numpy + Pillow，无第三方绘图库。
`generate.py` 用固定种子 `20261109` 生成三张 PNG：

| 图版 | 算法 | 要点 |
|---|---|---|
| 01 素数螺旋 | 萨克斯螺旋 `r=√n, θ=2π√n` | 厄拉多塞筛到 25 万；亮度 = 素数间隔；琥珀弧为 `k²+k+41` 的 40 个连续素数 |
| 02 元胞自动机 | 规则 90，零边界 | 4096 格 × 1800 步，取 `t∈[0,1600) × x∈[700,1900)` 一段；按局部密度分档上色 |
| 03 π 星尘 | 极坐标游走 | Chudnovsky 二进制分裂算 20 万位 π；10 条旋臂各取 18000 位数字做角向湍流 |

**制版**：所有线条与文字在 4 倍画布上绘制后用 LANCZOS 缩回，得到抗锯齿细线；
星点为高斯核累加（解析连续），最后统一加色合成 + 胶片颗粒 + 暗角。

**重跑**：

```bash
python generate.py          # 三张全画（约 40 秒）
python generate.py --only 1 # 只画某一张
```

`platelib.py` 是与 N°09《字》共用的图版语言（页眉页脚、刻度、色板）。


> 仓库内交付的三张成品图版为 JPEG（quality 95，2400×3600）；`generate.py` 输出的是 PNG，可自行转换。
