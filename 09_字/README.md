# 《字》 N°09

汉字「创」「造」的双联生成海报，2400×3600，与 N°06《数字星图》共用一套图版语言，强调色改为朱砂。

**操作**：打开 `index.html`，点任意一张放大，Esc 或点击关闭；手机上单列排列。

**技术**：Python 3.11 + numpy + Pillow，无第三方绘图库。
`generate.py` 用固定种子 `20261109`：

| 图版 | 算法 | 要点 |
|---|---|---|
| I 「创」 | 粒子场 | 字形蒙版 1400 px（4× 超采样）；字内按蒙版密度撒点，字外按 `Gaussian(σ=115)` 衰减逸散；1.2% 朱砂粒子作印泥碎屑 |
| II 「造」 | 地形等高线 | 字形经 FFT 高斯模糊（σ=34）成为高度场，按梯度归一化切出 27 级等值线；最亮一圈是字形边缘 |

**制版**：线条与文字在 4 倍画布上绘制后 LANCZOS 缩回；印章为实心朱砂块，字以阴文挖空。
字形用系统字体 `NotoSerifSC-VF`（Bold），不下载任何字体。

**重跑**：

```bash
python generate.py          # 两张全画（约 30 秒）
python generate.py --only 1 # 只画「创」
```


> 仓库内交付的两张成品图版为 JPEG（quality 95，2400×3600）；`generate.py` 输出的是 PNG，可自行转换。
