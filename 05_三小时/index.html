N° 05 — THREE HOURS

三小时

把三小时压进三分钟。一分钟一个时辰。
子夜、破晓、黎明，各占六十秒。

  • 60 BPM

  • 全曲手写合成

听法

建议戴耳机，音量调低——它不需要你注意它。全曲只有一个动机，在三个时辰里被移调、倒影、增值，听第二遍才认得出来。

首尾各留了一点静默，循环播放不会跳一下。

技术

钟声为非谐分音（1 : 2.76 : 5.40 : 8.93）加指数衰减；拨弦是 Karplus-Strong 延迟线；铺底是微失谐正弦叠层，经一极点低通扫频；混响为 Schroeder 四梳状二全通，湿声约三成。

Python + numpy 逐样本合成，无采样、无网络。另附 MIDI 工程，可在 DAW 里继续改。
