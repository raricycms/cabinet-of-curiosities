# 《涟漪》 N°01

一片没有边界的水面。鼠标是风，点击是投石；每一下点击同时激响一枚由落点决定的泛音——不是音效，是乐器。

**操作**：移动指针带起连续水痕；点击投石并响起一声（横向定音高、纵向定八度）；左下角开关声音与音量（`M` 键也可切换）；同一处连点三次会激起一个持续数秒的驻波。静置三秒水面自己开始零星落露水，八秒后下起小雨。

**技术**：2D 波动方程 `u′ = 2u − u₋₁ + c²∇²u` 的双缓冲 Float32 数值解，边缘吸收层 + 逐帧极轻扩散，网格按屏幕比例自适应；`ImageData` 逐像素由高度梯度求法线，做明暗与轻微色散；WebAudio 用 2–4 个正弦分音加指数衰减包络，过低通与噪声卷积混响，落点映射到 D 宫五声音阶。默认静音，首次点击后才出声。
