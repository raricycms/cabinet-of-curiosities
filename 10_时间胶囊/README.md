# 《时间胶囊》 N°10

一封写于 2026 年 11 月、封存至 2027 年 1 月 1 日 00:00 的信。在此之前，页面只显示一只信封、一枚火漆印和倒计时；正文以日期派生的密钥流加密存放，源码里读不到明文。

**操作**：等待。或点「尝试启封」看它拒绝你——拒绝语会随着尝试次数改变。日期到达后页面自动启封，并逐字写出信的内容；点击「收起」或按 Esc 可合上。

**技术**：FNV-1a 哈希 + mulberry32 伪随机数生成密钥流，与 UTF-8 明文逐字节异或后 Base64 存放；`file://` 下纯前端解密，无任何网络请求。火漆印、信封折角与投影均为 CSS 绘制。

**说明**：这枚封条是诗意的约定，不是密码学保险箱——懂技术的人当然可以拆开它。它只是在提醒：有些东西值得等一等。

**彩蛋**：如果提前很多次尝试启封，拒绝语会从"还不到时候"慢慢变成"你比大多数人都更想知道里面写了什么"。
