# 制作说明 / Colophon

这间屋子里的十二件展品，全部由原生技术手写完成。此文档记录它们是怎么做出来的，以及如何重新生成、修改。

## 技术栈

| 层 | 使用 |
|---|---|
| 页面 | 手写 HTML / CSS，无框架、无构建步骤 |
| 图形 | Canvas 2D（逐像素 ImageData / 逐路径绘制）、SVG、CSS 绘制 |
| 声音 | WebAudio 实时合成；离线渲染用 Python + numpy 手写合成器 |
| 图像 | Python + numpy + Pillow 程序化绘制（固定随机种子） |
| 文档 | Markdown + python-docx；A4 图录由 Chrome 无头模式打印 PDF |
| 校验 | 无头 Chrome + CDP：截图、控制台错误捕获、交互断言 |

所有页面在 `file://` 协议下直接运行，没有 `type="module"`、`fetch`、`XMLHttpRequest` 或任何外部请求。

## 各展品的生成方式

- **涟漪**：二维波动方程 `uₙ₊₁ = 2uₙ − uₙ₋₁ + c²∇²u` 的双缓冲数值解，`ImageData` 由高度梯度求法线做着色；落点映射五声音阶，WebAudio 合成泛音。
- **晶园**：扩散限制聚集（DLA）——随机游走者碰到已占据格即粘附；按极角取色，自动取景跟随包围盒；`toDataURL` 导出。
- **造物机**：FNV-1a → mulberry32 种子化 PRNG，驱动参数化 SVG 生物（5 种体型原型 × 轮廓波状变形 × 附肢/纹样/解剖结构）。
- **不存在的图书馆**：种子化中文语料与句式模板（书名 11 类句式、简介 6 类、手工摘录句库），书脊颜色与版式按年代映射。
- **三小时**：numpy 手写合成器——非谐分音钟声、Karplus-Strong 拨弦、微失谐正弦铺底、Schroeder 混响，离线渲染 44.1kHz WAV，另存 MIDI。
- **数字星图**：萨克斯螺旋（素数）、规则 90 元胞自动机、Chudnovsky 圆周率 → 极坐标星尘；4× 超采样后用 Pillow 缩放抗锯齿。
- **万物说明书 / 留白**：原创文本；DOCX 由 python-docx 生成；阅读页为手写排版。
- **字**：字形渲染成蒙版，分别当密度场（粒子）与高度场（等值线）使用。
- **时间胶囊**：日期字符串经 FNV-1a 派生密钥流，与 UTF-8 明文逐字节异或后 Base64 存放；到日期后纯前端解密。
- **预言机**：问题字符串哈希 → 24 支手写签的确定性映射；Canvas 由种子绘制印记；签条为 `writing-mode: vertical-rl` 竖排。
- **回声**：字符级衰减模型——漏字、相邻换位、用本句已有的字替换、极少量的虚词混入；每轮计算与原句的编辑距离，传到只剩一两字时停下。

## 目录中的工具

`_assets/` 里是制作与验收用的脚本，不是作品本体：

- `build_catalogue.mjs` —— 生成 A4 图录排印稿（`catalogue.html`），再用 Chrome 打印为 `奇珍室_图录.pdf`。改完展品截图后重跑即可。
- `build_postcards.mjs` —— 生成 A4 明信片排印稿（`postcards.html`，四张正反面），打印为 `奇珍室_明信片.pdf`。
- `audit.mjs` —— 用 CDP 打开每个页面，在 1440×900 与 390×844 两个视口截图，捕获 JS 异常与控制台错误，检查横向溢出与本地链接。
- `probe.mjs` —— 加载页面 → 执行一段 JS（模拟点击/输入）→ 截图，用来验证交互。
- `shots/` —— 图录所引用的截图。

重新生成图录：

```bash
node _assets/build_catalogue.mjs
```
