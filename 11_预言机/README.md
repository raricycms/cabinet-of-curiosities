# 《预言机》 N°11

写下此刻你想问的一件事，摇一支签。它不预测未来——它只是把你问的问题翻译成另一种说法：一首四行短诗、一句批注，以及一枚由问题本身生成的印记。

**操作**：在输入框写下问题（或点击签筒随机抽一支），按回车/点「摇一签」。签会被收进下方签筒（仅存于本机浏览器），可重看、可倒空；「抄下这一签」复制为纯文本。

**技术**：FNV-1a 字符串哈希 + mulberry32 伪随机数，把问题确定性地映射到 24 支签之一，并驱动 Canvas 绘制印记——同一个问题永远得到同一支签与同一枚印记。签面为 `writing-mode: vertical-rl` 竖排，签筒、摇动与落签为纯 CSS 动画。零外链，`file://` 直开。

**说明**：24 支签与批注均为手写。最后一支是空签。
