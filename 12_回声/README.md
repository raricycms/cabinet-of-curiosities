# 《回声》 N°12

一句话被一遍一遍地传下去。第一次只少了一个字，第二次语序歪了一点，第二十次它已经成了另一句话。传话的人都没有说谎。

**操作**：写下一句话（默认已填一句），回车或点「传下去」。每一行右侧是它与原句的相似度；「再传一次」换一组随机、重新传；「抄下这串回声」把整条链复制成文本。

**技术**：字符级衰减模型——每轮做 1–3 次操作：漏字（最常见）、相邻换位、用本句已有的另一个字替换、极少量的虚词混入。只用句子本身已有的字，所以它像是"被听错、被记漏"，而不是被随机涂改。每轮计算与原句的编辑距离；当句子只剩一两颗字时自动停下，并告诉你传到第几次就没人记得原句了。

**说明**：同一句话每次传下去的结果都不同（混沌），算法里保留种子。最后一行通常只剩几个字，那是最像"遗言"的部分。
