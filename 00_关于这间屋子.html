策展前言

有人把一只空文件夹
放在桌上。

他说：给你三个小时，随便创造点什么，只要它值得留下。

于是有了这间屋子。十二件展品，跨交互、生成艺术、声音、文学与装置。它们不解释自己——你碰一下，它们就动。

全部离线运行，双击即开，没有一件需要网络，没有一件会过期。

怎么打开HOW TO OPEN

双击门户打开 00_从这里开始.html（或目录里的 index.html，会自动跳转）。建议全屏。
随便推开一扇门从任意展品开始，没有正确顺序。每页左上角都能回到门户；门户里也有「随手推开一扇门」。
声音默认关闭除《三小时》外，所有声音都由你点击后才响。键盘可用 Tab / Enter 浏览。

它是怎么被做出来的HOW IT WAS MADE

全部是手写的原生 HTML / CSS / JavaScript：没有框架、没有构建步骤、没有外部依赖。图形是算出来的，声音是合成出来的，文字是写出来的。

  • 《涟漪》用二维波动方程数值解 + WebAudio 泛音合成；
  • 《晶园》用扩散限制聚集（DLA）与自动取景；
  • 《造物机》《不存在的图书馆》《预言机》用种子化伪随机数驱动 SVG 生物、中文文本与二十四支签；
  • 《三小时》由 numpy 手写加法合成、Karplus-Strong 拨弦与 Schroeder 混响，离线渲染 44.1kHz WAV，并另存 MIDI；
  • 《星图》《字》由 Python + Pillow 程序化绘制，4× 超采样，固定随机种子；
  • 《万物说明书》《留白》为原创文本，附 DOCX 排印版；
  • 《时间胶囊》把日期派生的密钥流与明文异或，到日期后纯前端启封。
另外还有两件可以打印的东西：A4 展品图录与四张一套的明信片。

三条约定PROMISES

  1. 不含任何真实人物的信息没有人名、学校、单位、账号、网址，也没有引用任何私人文件。作品里出现的人名全部虚构。
  2. 不联网没有 CDN、没有外链字体、没有统计脚本。断网、拔掉网线、把整个文件夹拷进一只旧 U 盘，它们仍然完好。
  3. 可被继续修改每件作品都是单文件，代码没有压缩，生成脚本带注释与固定种子。欢迎拆开、改参数、重跑。
